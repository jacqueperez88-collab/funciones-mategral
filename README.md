# 📐 Funciones Matemáticas - Recurso Interactivo

[![CC BY-SA 4.0](https://img.shields.io/badge/License-CC%20BY--SA%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-sa/4.0/deed.es)

Recurso educativo web interactivo desarrollado para los estudiantes de **Primer Año** de la **Tecnicatura Universitaria en Desarrollo Web (TUDW)** y la **Tecnicatura Universitaria en Administración de Sistemas y Software Libre (TUSSL)** de la Universidad Nacional del Comahue.

Este proyecto busca facilitar la comprensión de las funciones matemáticas mediante gráficos dinámicos, teoría clara y ejercicios prácticos con autocorrección.

---

## ✨ Características Principales

- 📖 **Teoría completa:** Definición de función, función lineal, cuadrática, cúbica y definida por partes.
- 🎛️ **Gráficos interactivos:** Sliders dinámicos construidos con HTML5 Canvas para visualizar cómo los parámetros ($a, b, h, k$) modifican la gráfica.
-  **Fórmulas en LaTeX:** Renderizado profesional de notación matemática mediante MathJax.
- 📝 **Ejercicios prácticos:** Problemas de las fichas de la cátedra con soluciones ocultas para que el estudiante pueda autocorregirse.
-  **Diseño Responsive:** Adaptable a computadoras, tablets y celulares.
- 🎨 **Estética cuidada:** Interfaz limpia con tonos verdes pastel.

## 🔄 Guía de Reutilización para Docentes y Desarrolladores

Este recurso es **Software y Contenido Educativo Abierto**. ¡Sentite libre de adaptarlo a tu propia cátedra!

### ¿Cómo modificarlo?
1. **Fork (Bifurcar):** Hacé un "Fork" de este repositorio en tu propia cuenta de GitHub.
2. **Editar:** Modificá el archivo `index.html` usando cualquier editor de código (VS Code, Sublime Text, Notepad++).
   - **Cambiar colores:** Buscá los códigos hexadecimales en la sección `<style>` (ej: `#a8d5ba`, `#7bc47f`).
   - **Agregar ejercicios:** Copiá y pegá los bloques `<div class="exercise">` y ajustá el contenido y el LaTeX.
   - **Cambiar autoría:** Editá las secciones `<header>` y `<footer>`.
3. **Publicar:** Subí tus cambios y activá GitHub Pages en la configuración de tu repositorio, o subilo a Netlify/Vercel.

### Stack Tecnológico
- **HTML5** (Estructura semántica)
- **CSS3** (Diseño, Flexbox, Animaciones)
- **JavaScript (Vanilla)** (Lógica de pestañas, interactividad de sliders y dibujo en Canvas)
- **MathJax 3** (Renderizado de fórmulas LaTeX)
